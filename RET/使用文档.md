# retrieval_v1.py 使用文档

## 功能说明

基于 BM25 + 关键词检索 + RRF 融合的混合检索工具，从论文元数据中检索与问题最相关的 Top-K 结果。

## 目录结构

```
RET/
├── retrieval_v1.py          # 主脚本
├── 使用文档.md               # 本文件
├── top3_results.txt         # TXT 格式结果
├── data/                    # 源头数据目录（存放论文 JSON 元数据）
└── coarse_sort_result/      # 检索结果输出目录
    └── top3_results.json    # JSON 格式结果
```

## 使用步骤

### 1. 准备数据

将论文元数据 JSON 文件放入 `data/` 目录。每个 JSON 文件需包含以下字段：

| 字段 | 说明 |
|------|------|
| `id` | 论文唯一标识 |
| `title` | 论文标题 |
| `year` | 发表年份 |
| `source_type` | 来源类型 |
| `text` | 全文 |
| `text_summary` | 文本摘要 |
| `image_summary` | 图片摘要列表 |
| `evidence_level` | 证据等级 |

### 2. 修改检索参数

编辑 `retrieval_v1.py` 顶部三个变量：

```python
QUESTION = "大语言模型的推理与训练方法"  # 检索问题（自然语言）
KEYWORDS = "大语言模型 推理 训练"         # 关键词（空格分割，用于分词）
TOP_K = 3                                 # 返回结果数量
```

- **QUESTION**：用于 BM25 检索的自然语言问题
- **KEYWORDS**：用于关键词匹配，空格分割后自动分词
- **TOP_K**：最终返回的 Top-K 结果数量

### 3. 运行

```bash
python retrieval_v1.py
```

### 4. 查看结果

运行后在项目根目录生成 TXT 文件，在 `coarse_sort_result/` 目录生成 JSON 文件：

- **top3_results.txt**：简洁结果，位于 `retrieval_v1.py` 同级目录，仅含 Rank、关联度、ID、Title、年份、来源
- **coarse_sort_result/top3_results.json**：完整结果，含 rank、score、raw_rrf_score、metadata

## 检索原理

1. **BM25 检索**：对文档进行分词后使用 BM25Okapi 算法计算相关性
2. **关键词检索**：基于查询词与文档/标题的词集合覆盖率加权打分（文档 0.7，标题 0.3）
3. **RRF 融合**：对两种检索结果进行倒数排名融合，得到最终排序
