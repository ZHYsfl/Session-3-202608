# 三个赛道提示词

本包是三条赛道Prompt的独立正式交付物，不包含模型API、500题批处理或最终产品代码。

## 三条赛道

### 赛道一：临床证据｜找证据

- 用户：医生、医学生、科研人员。
- 目标：从论文、试验和指南中找对证据并给出可追溯回答。
- 重点：正确性、证据等级、引用真实性和研究局限。

### 赛道二：健康营养｜讲明白

- 用户：普通消费者。
- 目标：把健康营养证据用通俗、克制的语言说明白。
- 重点：可读性、证据等级、适用人群、避免过度建议和固定免责声明。

### 赛道三：对比评估｜测清楚

- 用户：评估人员。
- 目标：比较同一底座的纯LLM与RAG回答。
- 包含：统一回答Prompt、纯LLM上下文、RAG上下文、裁判Prompt和评分JSON结构。
- 裁判每题只评判一次，A/B身份随机，允许平局。

## 文件

- `three_track_prompts.json`：程序直接读取的完整配置。
- `PROMPT_GUIDE.md`：每套提示词的变量和使用方式。
- `question_and_metadata_interfaces.json`：Prompt所引用的数据结构摘要。

## 版本管理

正式实验时应固定Prompt版本。第9部分包内的 `evaluation_prompts.snapshot.json` 是本文件的运行快照；如果正式修改本包Prompt，需要重新复制到第9部分并记录版本，避免实验过程中提示词漂移。
