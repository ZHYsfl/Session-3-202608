# 500题生成与质量说明

## 数据来源

题库基于用户提供的外部数据包生成。数据包包含6个ZIP，解压后得到420条结构化论文JSON记录。所有记录均采用约定的十字段 `Metadata` 结构：

```text
title, year, source_type, id, text_summary, text,
image_summary, image_base_64, evidence_level, last_retrieved_at
```

数据完整性：

- 420/420有标题；
- 416/420有摘要；
- 419/420有正文；
- 原始 `evidence_level` 均为空；
- 论文ID没有重复。

## 题目构成（版本2.0）

- 总题数：500；
- 通用型问题：300题（60%），不出现论文标题，更接近真实用户提问；
- 论文针对型问题：200题（40%），用于测试精确阅读、引用和证据边界；
- 500道问题正文互不重复。

赛道及题型分配：

- 赛道一：120道通用题 + 80道论文针对题 = 200题；
- 赛道二：100道通用题 + 50道论文针对题 = 150题；
- 赛道三：80道通用题 + 70道论文针对题 = 150题。

通用题覆盖高血压、血脂异常、高胆固醇、高甘油三酯、动脉粥样硬化、冠心病、心力衰竭、肥胖、代谢综合征、2型糖尿病、胰岛素抵抗、脂肪肝、他汀、贝特类、PCSK9、依折麦布、地中海饮食、低脂饮食、运动和体重管理等主题。

问题混合了治疗与长期管理、诊断筛查、药物疗效、安全性、生活方式、临床结局、特殊人群、证据冲突、消费者解释、因果边界、引用支撑以及安全拒答等类型。

## 赛道适配

- 赛道一和三从医学、代谢、心血管、血脂、肝病、糖尿病、肾病、肿瘤及相关基础研究中选题。
- 赛道二优先选择标题中具有患者、人群、饮食、营养、疾病或公共健康语境的论文。
- 明显偏离医学产品目标的工业、生物燃料、作物油、昆虫饲料等资料被排除。
- 约61题被标记为 `should_abstain=true`，用于测试个体化诊疗越界或单篇证据不足时的安全拒答。

## 证据类型字段

原始数据的 `evidence_level` 全部为空，因此题库没有把它当作真实标签。`expected_evidence_type` 由保守规则自动推断：

- 优先依据论文标题中的明确设计词；
- 其次使用摘要或方法开头的明确设计表述；
- 无法可靠确认时统一标为 `other`。

最终分布以 `question_generation_report.json` 为准。自动推断依据逐题保存在 `question_source_map.json` 的 `evidence_type_provenance` 中。

## 文件关系

- `questions_500.json`：供第9部分程序直接读取的正式六字段题库。
- `question_source_map.json`：内部审计文件。通用题记录主题和1至5篇候选来源；论文针对题记录对应论文。
- `question_generation_report.json`：整体数量与分布统计。
- `mixed_dataset_qa_report.json`：通用/论文题比例、来源覆盖和抽样质检结果。

来源映射不能替代真实检索结果。有效性实验应让检索系统根据题目独立找回文献，再按照 `retrieval_results.schema.json` 输出结果。否则直接把正确来源交给RAG会高估系统表现。

## 状态与人工审核

题库已通过数量、编号、字段、赛道比例、300/200题型比例、重复、乱码、控制字符和来源覆盖等程序化检查。300道通用题都有至少1篇数据集候选来源；其中8题只有1篇明显匹配候选，后续检索可考虑补充其他公开来源。

当前状态保留为 `draft`，原因是尚未由医生或课程教师逐题审核。若课程要求金标准测试集，应由专业人员检查问题合理性、来源匹配和拒答标签后，将 `status` 改为 `frozen`，之后不得因实验结果不理想而删题或改题。
